# AngstiFun ($ANGSTIFUN)

Мем-коин лендинг в духе сказки на ночь: Pan — маленький синий дух из Neverdump Land, который каждую
ночь прилетает к падающим портфелям с капсулой в цветах pump.fun, чтобы никто никогда не вырастал и
не продавал дно.

## Как задеплоить
Чистый статический сайт без сборки — `index.html` + `style.css` + `script.js` + `assets/`.

1. Загрузить содержимое папки в репозиторий на GitHub (drag-and-drop через веб-интерфейс).
2. На vercel.com → Add New Project → Import этот репозиторий → Deploy (build command не нужен).

## Перед запуском токена
Открой `script.js`, впиши в объект `CONFIG`:
- `CA` — контракт токена
- `BUY_URL` — ссылка на покупку (например pump.fun)
- `CHART_URL` — ссылка на Dexscreener
- `X_URL` / `TELEGRAM_URL` — соцсети

После этого кнопки заработают, копирование CA включится, а карточки в разделе "Pump Dust — Live Count"
подтянут live-цену/капу/ликвидность/объём с DexScreener автоматически.
